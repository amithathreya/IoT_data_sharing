3.4   Software Requirements

The software requirements specify the essential tools, frameworks, and libraries used for building the application. This includes the operating system, programming language, web framework, and machine learning libraries. The project uses open-source technologies like Python, Node.js, and React, which are well-suited for developing robust, scalable, and interactive web applications integrated with machine learning models.

Table 3.4: Software Requirement Specification
Component Specification
Operating System Windows 10/11 or any Linux-based OS for local development; Raspberry Pi OS 64-bit for edge device.
Frontend React.js, Vite, HTML5, CSS3, JavaScript, Tailwind CSS, Recharts for dynamic telemetry visualization.
Backend Framework Node.js (Express.js) for REST and WebSocket APIs; Python 3.10+ (Web3.py, Pika, liboqs).
Tools used Docker & Docker Compose, RabbitMQ Message Broker (TLS 1.3), Hyperledger Besu (IBFT 2.0), TensorFlow / Keras, OpenSSL, VS Code.
