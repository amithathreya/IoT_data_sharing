3.3   Hardware Requirements

The hardware requirements outline the minimum and recommended system configurations needed to develop, train, and deploy the application. Since the project involves machine learning model training and real-time predictions through a web interface, the system must be capable of handling moderate computational tasks efficiently. Adequate memory, processing speed, and storage are necessary to ensure smooth development and testing operations.

Table 3.3: Hardware Requirement Specification
Component Specification
Processor Intel Core i5/i7 or AMD equivalent for smooth processing of ML tasks; ARM Cortex-A72 (Raspberry Pi 4) for edge sensing node.
RAM Minimum 8GB (16GB recommended) to handle data preprocessing and model execution.
Storage At least 256GB SSD (512GB recommended) for faster access to model and dataset files; 32GB MicroSD for Edge Pi.
Display Standard resolution display compatible with modern web browsers.
Network Stable internet connection for online access and cloud deployment.
