Table 3.2: Non Functional Requirements
Requirement Description
Performance The system must deliver results within seconds after data submission.
Usability The user interface must be simple, intuitive, and accessible to non-technical users.
Scalability The system should handle increasing users and data with ease using cloud deployment.
Maintainability The system code should be modular and well-documented for easy maintenance and updates.
Security Ensures secure login, data encryption, and restricted access based on user roles.
Compatibility The system should be compatible across major browsers and devices (desktop, mobile).
Reliability The system should consistently produce accurate and repeatable results.
