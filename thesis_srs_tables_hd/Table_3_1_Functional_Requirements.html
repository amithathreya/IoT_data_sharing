Table 3.1: Functional Requirements
Requirement Description
MIoT Device Registration The system should allow authorized MIoT nodes or workers to participate in the distributed security framework.
Local Model Training Each participant worker should train the machine learning model using its own dataset without directly sharing the raw data with other workers.
Federated Model Aggregation The system should collect model updates from the participating workers and create an updated global model through Federated Learning.
Anomaly/Intrusion Detection The learning model should recognize network behaviors which are likely to be abnormal or malicious.
Secure Model Communication Model updates and corresponding communication should be secured by utilizing secure communication means.
Blockchain Transaction Management The system should log relevant security and verification transactions via the Blockchain layer.
Transaction Integrity Verification The system should provide tamper-resistant verification of logged blockchain transactions.
Post-Quantum Security The system should adopt post-quantum cryptography approaches to prevent potential quantum-based attacks.
Communication Efficiency Evaluation The system should monitor the performance associated with communication processes during distributed learning and data exchange.
